## 本次实现

- **4D 入站分段**：`incoming.js` 的 admit/parse/divert 分别处理准入、引用/媒体/语音解析、管理命令与挂起回答/静默分流；`dispatchIncoming` 的模式派发与时间线仍在 bridge。`admission.js` 统一私聊与群准入，`segments.js` 统一媒体提取，白名单预设通知保留独立入口。
- **4B-2 遗留发送**：`image-send.js` 从 bridge 抽离选图、回源、HTTP 发送与记账，经过同会话发送队列，跨会话互不阻塞。慢查询完成后复核准入，发送失败不记成功；修复同前缀兄弟目录被误认为图库内部路径的问题。
- **按计划追加 4E**：`social-state.js` 统一默认值、唤醒安全和状态读写；`bili-runtime.js` / `bili-sharing.js` 负责浏览与推荐选群。请求提示与角色卡读取分别放入 `content-request.js` / `role-hint.js`。可变配置、模式、观看状态使用显式依赖与实时 getter。
- **状态正确性**：补读原先只保存的 pendingWakeReasons、lastAutoAt、autoAtTimes。`session-tracking.js` 让管理员重置、模式轮换、上下文超限和控制台清理共同释放回合/发送工具追踪/自动 @ 标记/B 站初判等待者；上下文轮换仍保留群聊记忆。
- **测试迁移**：业务行为直接 import 模块；跨模块结构护栏集中到 `test-bridge-wiring.mjs`。未把 bridge 源码拼接到 helper 规避计数；保留必要接线约束。
