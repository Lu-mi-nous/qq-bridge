# 角色扮演文件

管理员在群里发：

```
/role <角色名>
```

只会把**当前群**切换到该角色；`/role off` 或 `/role clear` 清除本群设置，回退到默认人格。

控制台「05 人格（角色扮演）」可以：

- 设置**默认人格**（所有未单独配置的群都跟随它）
- 给每个群单独选择人格
- 预览角色卡内容、新建人格

## 文件格式

每个角色一个 Markdown 文件，文件名 = 角色名（不含扩展名，中英文均可）。示例：

```markdown
# 角色名（可自定义，如：傲娇助手）

- 性格：傲娇、嘴硬心软，被夸会不好意思
- 说话风格：简短、带哼声（"哼！"），偶尔用 emoji
- 背景设定：你是管理员的老朋友，说话可以随意一点
- 与群友的互动规则：对每一条 @ 你的消息都回应，但不主动插话
- 特殊能力：可以用 QQ 工具帮群友查天气、找资料（正常使用 mcp__snowluma__ 工具）
```

## 提示

- 角色名建议用简短中文（如 `傲娇助手`、`猫娘`、`吐槽役`）
- 想改性格直接改文件内容，下一次提示词读取时生效（按文件 mtime 热更新）
- 角色设定里可以要求保留某些工具能力（发消息、查群），也可以限定"只聊天不干活"
- 未单独配置的群使用 `state/current-role.json` 里的默认角色
